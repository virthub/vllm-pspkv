# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.

You can contact the maintainers directly via email (if a contact address is provided in the repository profile) or by opening a **draft issue** with a clear description of the issue and marking it as confidential (if your platform supports that). We will acknowledge your report as soon as possible and work on a fix.

Please do not disclose the vulnerability publicly until we have released a patch.

## Scope

This policy applies to the `vllm-pspkv` fork only. For vulnerabilities in the upstream vLLM project, please refer to the official vLLM security policy.
